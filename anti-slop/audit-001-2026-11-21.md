# Antislop Audit 001 (2026-11-21)

Scope: Perombakan UI/UX Matchday Hub & Player Model (`CareerShell.gd`, `KiniTab.gd`, `PixelAvatar.gd`, `PixelJerseyIcon.gd`, `LineupScreen.gd`, `ScheduleScreen.gd`).
Mode: **AFTER** (audit setelah implementasi selesai; belum ada perubahan lanjutan sampai nomor temuan disetujui).

## Daftar Temuan

1. **[HIGH] [R-32] Keyboard Escape & Focus Indicator**: Modal overlay (`LineupScreen.gd`, `ScheduleScreen.gd`, `_energy_modal` di `CareerShell.gd`) belum menutup saat tombol `Escape` ditekan, dan tombol transparan nav tile di `CareerShell.gd` memakai `StyleBoxEmpty` untuk state `focus` sehingga indikator fokus keyboard tidak terlihat.
2. **[HIGH] [R-39] Distinct Hover/Pressed State pada Tombol Jersey & Line-Up**: Tombol transparan di `_make_kit_picker_row` dan `_make_lineup_preview_button` (`KiniTab.gd`) belum memiliki highlight visual khusus untuk state `hover`/`pressed` seperti sel pemain di `LineupScreen.gd`.
3. **[HIGH] [R-25] Kontras Warna Label Form Kosong (`-`)**: Label `"-"` pada strip 5 laga terakhir di `KiniTab.gd` memakai `#64748B` di atas `#1B2A40` (rasio kontras ~2.9:1, di bawah batas WCAG AA 4.5:1 untuk teks kecil).
4. **[HIGH] [R-03] Target Sentuh Kompak pada Tombol Utilitas Top Bar**: Tombol `+` (`24x24`), `⚙` (`30x30`), dan `☰` (`30x30`) di baris atas `CareerShell.gd` lebih kecil dari standar target sentuh 44px bila dijalankan di layar sentuh/mobile.
5. **[HIGH] [R-27] Empty State Matchday Saat Fixture Kosong**: Bila `schedule` atau `clubSquad` kosong, `KiniTab.gd` merender lapangan tanpa pesan status yang menjelaskan penyebab dan aksi lanjutannya.
6. **[MEDIUM] [R-19] Loop Animasi Idle Tanpa Opsi Pause/Reduced Motion**: Kedua kapten terdepan di tunnel `KiniTab.gd` menjalankan `anim_mode = "IDLE"` terus-menerus tanpa mengikuti preferensi pengurangan animasi.
