# Antislop Audit 004 (2026-11-22)

Scope: Perombakan UI/UX Menu `BURSA` / `KOMP.`, Penghapusan Menu Duplikat `JADWAL`, Aturan Zona Kualifikasi & Promosi/Degradasi per Liga, serta Overlay `NEGARA`, `KLASEMEN`, dan `TOP SKOR` (`DuniaTab.gd`, `CompOverlays.gd`, `CareerState.gd`, `UITheme.gd`).
Mode: **AFTER** (audit setelah implementasi selesai; nomor dilanjutkan dari Audit 003).

## Daftar Temuan

15. **[HIGH] [R-03] Target Sentuh Pill Sub-Kompetisi, Alfabet Negara & Switcher Divisi**: Tombol pill sub-kompetisi dan tombol pilih liga di `DuniaTab.gd` bertinggi `30px`, tombol huruf alfabet (`30x28px`) dan tombol divisi (`28px`) di overlay `NEGARA`, serta tombol cepat `K1/K2/K3` (`30x24px`) di overlay `KLASEMEN` (`CompOverlays.gd`) berada di bawah standar target sentuh `44px`.
16. **[MEDIUM] [R-25] Ukuran Teks Mini pada Header Kolom, Tag PO & Legenda Zona**: Label `PO` (`font_size = 9`) di `DuniaTab.gd` serta header kolom statistik dan teks legenda warna zona (`font_size = 10`, `UITheme.TEXT_MUTED`) di `CompOverlays.gd` berukuran kecil dan dapat menyulitkan pembacaan cepat pada layar kecil.
17. **[MEDIUM] [R-32] Manajemen Fokus Keyboard Overlay Fullscreen**: Ketiga overlay di `CompOverlays.gd` (`NEGARA`, `KLASEMEN`, `TOP SKOR`) sudah mendukung tombol `Escape` untuk menutup, tetapi belum secara otomatis memindahkan fokus keyboard saat overlay muncul dan mengembalikannya ke tombol pemicu di `DuniaTab.gd` saat ditutup.
18. **[LOW] [R-39] Penanda Non-Warna untuk Zona di Tabel Klasemen Penuh**: Pada overlay `KLASEMEN` (`CompOverlays.gd`), pembeda zona tiap baris (`ELITE`, `EUROPA`, `CHALLENGE`, `PROMOSI`, `DEGRADASI`) hanya memakai garis vertikal berwarna `3px` yang bergantung pada legenda bawah, tanpa tooltip atau penanda simbol langsung di baris untuk pengguna dengan gangguan penglihatan warna.
